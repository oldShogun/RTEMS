# RTEMS - Real-Time Electromechanical System Modeler

## Описание алгоритма

RTEMS - это программный комплекс для моделирования электромеханических процессов в энергосистеме в режиме реального времени, с возможностью определения и применения управляющих воздействий для сохранения устойчивости системы.

### Ключевые особенности алгоритма:

1. **Непрерывный мониторинг колебательной структуры энергосистемы**:
   - Обработка данных от PMU (синхрофазоров) с частотой до 50 измерений в секунду
   - Выделение колебательных подсистем по критерию одинакового знака отклонения вращения ротора генератора относительно частоты ЦИ системы
   - Определение связанных пар подсистем с наибольшей скоростью изменения разницы их средневзвешенных углов

2. **Механизм активации прогнозирования**:
   - Запуск при превышении уставки разницы углов (например, 20 градусов)
   - Сбор статистики колебаний для последующего анализа

3. **Двухуровневое прогнозирование**:
   - **Быстрая ветка**: упрощенная модель прогнозирования без полного расчета сети и генераторов
   - **Основная ветка**: точный расчет с использованием метода итерационной увязки уравнений сети и генераторов
   - Адаптивный шаг метода предиктор-корректор для моделирования генераторов
   - Выбор результата прогнозирования на основе временных ограничений

4. **Расчет управляющих воздействий (алгоритм ПОСЛЕ)**:
   - Расчет кинетической энергии колебательной подсистемы
   - Оценка потенциального барьера согласно методике Лизалека
   - Определение типа и объема управляющих воздействий (УВ)
   - Поддерживаемые типы УВ: ОГ (отключение генераторов), ОН (отключение нагрузки), ОЛ (отключение линий), команды на снижение мощности и изменение возбуждения генератора

5. **Проверка достаточности управляющих воздействий**:
   - Моделирование системы после применения УВ
   - Проверка сохранения устойчивости энергосистемы
   - Корректировка УВ при недостаточной эффективности (обратная связь)
   - Ранжирование УВ по эффективности и скорости реализации

6. **Формирование управляющих команд**:
   - Автоматическое формирование и отправка команд без участия оператора
   - Логирование всех действий и решений системы

7. **Расширяемость и модульность**:
   - Модульная архитектура с использованием паттернов проектирования
   - Возможность замены или модификации отдельных компонентов
   - Поддержка подключаемых модулей с различными алгоритмами

8. **Параметры системы**:
   - Масштаб системы: до 800 узлов, 1100 линий, 130 генераторов
   - Данные обновляются до 50 раз в секунду от устройств PMU

## Требования к системе

- **Язык программирования**: C++17 или выше
- **Система сборки**: CMake 3.15+
- **Подходящие компиляторы**: GCC 8+, MSVC 2019+, Clang 9+
- **Дополнительные библиотеки**: 
  - Eigen (для матричных вычислений)
  - spdlog (для логирования) 
  - nlohmann/json (для работы с JSON)
  - Qt (для пользовательского интерфейса)
